# Karma Card Game
*Also known as shithead*

A karma/shithead card game for the KorGE game engine.

Currently working on the core game logic/data. Proper documentation and tech demos to follow. :)

You'll need to install Amazon Corretto 22 JDK from your favourite source

Unit tests for the game logic/data live in `test/unit`

These can be run with `./gradlew :cleanJvmTest :jvmTest --tests "unit.*"` from the repo root dir.

You can find the KorGE documentation here: <https://docs.korge.org/korge/>
